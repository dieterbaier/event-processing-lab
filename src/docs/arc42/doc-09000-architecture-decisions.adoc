== ADR-001: Use Kafka as Event Backbone



See xref:adr-001-use-kafka-as-event-backbone.adoc[ADR-001: Use Kafka as Event Backbone] for full details.

=== Summary

Use Apache Kafka as the central event transport mechanism for the Event Processing Lab.

== ADR-002: Use JSON Serialization for First Iteration



See xref:adr-002-use-json-serialization.adoc[ADR-002: Use JSON Serialization for First Iteration] for full details.

=== Summary

Use JSON format for event serialization in the initial implementation.

== ADR-003: Keep Spring Boot Optional, Use Plain Java



See xref:adr-003-keep-spring-boot-optional.adoc[ADR-003: Keep Spring Boot Optional, Use Plain Java] for full details.

=== Summary

Prefer plain Java implementations where simpler, keep Spring Boot optional.

== ADR-004: Separate Esper and Flink Implementations



See xref:adr-004-separate-implementations.adoc[ADR-004: Separate Esper and Flink Implementations] for full details.

=== Summary

Maintain separate implementations for Esper and Flink to enable direct comparison.
