[[shipment-start-flow]]
== Shipment Start Flow

*Steps:*

. OrderCreated and PaymentReceived events are processed
. ShipmentStarted event is published
. Consumers receive ShipmentStarted event
. Correlation with previous events: Kafka Consumer (manual, cached order + payment), Esper (order-to-shipment pattern), Flink Basic (stateful validation that shipment follows payment), Flink CEP (complete-flow pattern)
