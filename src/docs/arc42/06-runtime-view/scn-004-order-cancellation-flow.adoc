[[order-cancellation-flow]]
== Order Cancellation Flow

*Steps:*

. OrderCreated event is processed
. OrderCancelled event is published (due to customer request or timeout)
. Consumers receive OrderCancelled event and process it accordingly
. Different handling: Kafka Consumer (logging + cache cleanup), Esper (cancellation pattern), Flink Basic (stateful cancellation), Flink CEP (cancellation pattern matching)
