== QS-013-monitoring-effectiveness: Monitoring Effectiveness



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Operator
| Stimulus | Needs the current processing health of the system
| Environment | Normal operation
| Artifact | Logs and metrics of the modules
| Response | Key indicators such as throughput, lag, and errors are visible
| Response Measure | Throughput, consumer lag, and error rate observable without code changes
|===

=== Rationale

Observability lets learners see and measure runtime behavior.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
