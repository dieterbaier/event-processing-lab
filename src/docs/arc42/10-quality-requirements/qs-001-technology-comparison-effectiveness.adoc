== QS-001-technology-comparison-effectiveness: Technology Comparison Effectiveness



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Integration architect using the lab
| Stimulus | Needs to select an event-processing technology for a given requirement
| Environment | Normal evaluation session using the lab and its comparison documentation
| Artifact | The four technology implementations and the technology-comparison docs
| Response | The architect compares Kafka, Esper, Flink, and Flink CEP against the requirement and selects one with justification
| Response Measure | Appropriate technology chosen for at least 80% of a set of requirement scenarios
|===

=== Rationale

Comparability is the primary learning outcome of the lab.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
