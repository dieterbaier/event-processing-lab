== QS-002-learning-objective-achievement: Learning Objective Achievement



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Learner
| Stimulus | Completes the guided scenarios across the modules
| Environment | Normal self-paced learning
| Artifact | Lab modules and arc42 documentation
| Response | The learner can explain each technology's trade-offs in their own words
| Response Measure | At least 4 of 5 stated learning objectives demonstrated in a self-assessment
|===

=== Rationale

The lab exists to build transferable understanding, not just runnable code.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
