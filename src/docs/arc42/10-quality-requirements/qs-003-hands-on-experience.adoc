== QS-003-hands-on-experience: Hands-on Experience Effectiveness



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Learner
| Stimulus | Runs an order-lifecycle scenario end to end (produce then process)
| Environment | Local development with Kafka started via docker-compose
| Artifact | Event producer and one processing module
| Response | The scenario runs and emits observable processing results
| Response Measure | First successful end-to-end run achieved within 30 minutes of initial setup
|===

=== Rationale

Fast first success keeps learners engaged and lowers the barrier to entry.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
