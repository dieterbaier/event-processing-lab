== QS-005-debugging-effectiveness: Debugging Effectiveness



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Developer
| Stimulus | Observes an unexpected processing result
| Environment | Local development
| Artifact | Logs of the relevant processing module
| Response | The developer locates the responsible component or rule
| Response Measure | Root cause identified within 15 minutes using logs alone
|===

=== Rationale

Simple, transparent code and logging make behavior easy to reason about.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
