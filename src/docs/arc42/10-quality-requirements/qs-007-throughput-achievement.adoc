== QS-007-throughput-achievement: Throughput Achievement



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Event producer acting as load generator
| Stimulus | Emits a sustained stream of events
| Environment | Single-node local Kafka with default configuration
| Artifact | Kafka consumer and processing modules
| Response | Events are processed without unbounded consumer lag
| Response Measure | Sustains at least 1,000 events/sec with consumer lag remaining bounded
|===

=== Rationale

Throughput behavior is a key dimension of the technology comparison.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
