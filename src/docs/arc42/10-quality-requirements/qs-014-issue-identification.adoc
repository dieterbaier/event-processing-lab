== QS-014: Issue Identification



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Operator
| Stimulus | An error or event loss occurs
| Environment | Operation under a fault condition
| Artifact | Logs and the module's error handling
| Response | The failing module and cause are surfaced
| Response Measure | Failing module identified from logs within 10 minutes
|===

=== Rationale

Fast fault localization supports the reliability comparison.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
