== QS-008: Consumer Scaling



=== Status

Proposed. AI-assisted; the response measure is a reviewable target.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Operator
| Stimulus | Increases the number of consumer instances in the group
| Environment | Normal operation with a partitioned topic
| Artifact | Kafka consumer group
| Response | Partitions rebalance and aggregate throughput increases
| Response Measure | Near-linear throughput gain up to the partition count (within +/-20%)
|===

=== Rationale

Consumer-group scaling demonstrates Kafka's horizontal scalability.

=== Assumptions

* Values are initial targets for a single-node learning setup and must be reviewed.
