= TD-008: Externalized Configuration



== Status

Proposed.

This technical debt item is AI-assisted. It identifies work needed for review and does not decide acceptance.

== Technical Debt Statement

Because configuration is hardcoded in some places, **the modules are less flexible and harder to configure** for different environments and use cases.

== Details

* **Module**: event-producer, kafka-consumer
* **Impact**: Maintainability gap - configuration cannot be changed without code changes
* **Priority**: Medium
* **Type**: Maintainability gap

== Resolution

Externalize all configuration to configuration files or environment variables, following 12-factor app principles.

== Acceptance Criteria

* All configuration is externalized (no hardcoded values)
* Configuration can be set via environment variables
* Configuration files use a standard format (YAML, properties, etc.)
* Default values are provided for development
