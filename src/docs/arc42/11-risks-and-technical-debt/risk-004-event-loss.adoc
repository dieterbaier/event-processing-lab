[[risk-004-event-loss]]
= RISK-004: Event Loss During Processing



== Status

Proposed.

This risk is AI-assisted. It identifies a concern for review and does not decide risk acceptance.

== Risk Statement

Because event processing involves multiple steps and potential failures, **event loss may occur during processing**, leading to incomplete or incorrect results.

== Assessment

[cols="1,3", options="header"]
|===
| Field
| Value

| Likelihood
| Low

| Impact
| High

| Priority
| Medium

| Timeframe
| Near-term

| Confidence
| High
|===

== Mitigation Options

* Use durable commits in Kafka consumers to prevent data loss
* Monitor consumer offsets to detect processing gaps
* Implement end-to-end acknowledgments where possible
* Use transactional processing for critical operations
* Implement dead letter queues for failed events

== Decision or Acceptance

The risk is currently mitigated through Kafka's durability guarantees. For this learning project, minimal event loss is acceptable.
