= 3. System Scope and Context

[semantic-anchor: event-processing-lab]

== 3.1. System Overview

The Event Processing Lab is a **learning platform** that demonstrates event processing technologies through a common order lifecycle use case. It provides comparable implementations of event processing patterns across Kafka, Esper, Apache Flink, and Flink CEP.

=== System Type

* **Category**: Learning Platform / Technology Comparison
* **Domain**: Event Processing / Complex Event Processing (CEP)
* **Purpose**: Education and architectural comparison
* **Primary Users**: Integration Architects, Technical Leads, Software Engineers

== 3.3. System Scope

=== Functional Scope

The system provides:

* Event model definition and serialization
* Event production (Kafka producer)
* Event consumption (Kafka consumer)
* Complex event pattern detection (Esper CEP)
* Stream processing (Flink DataStream)
* Pattern detection (Flink CEP)
* Runtime scenario demonstration
* Comparison framework

=== Non-Functional Scope

The system demonstrates:

* Scalability characteristics
* Operational complexity
* State handling approaches
* Rule complexity
* Architectural trade-offs

=== Not in Scope

The system does NOT provide:

* Production-grade deployment
* Enterprise security (authentication, authorization, encryption)
* High-availability configurations
* Performance optimization for production load
* Binary serialization (Avro, Protobuf) in first iteration
* Spring Boot integration (optional)
* Monitoring and alerting infrastructure
